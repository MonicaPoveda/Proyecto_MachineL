CRISP-DM Phase 3: Data Preparation

This phase processes malicious and legitimate URL indicators to create a balanced dataset ready for machine learning.

Model approach: binary classification

Malicious indicators are labeled 1, while legitimate domains are labeled 0. URLs are normalized and converted into numerical features before the data is split into training and test sets.

Executed steps

  1. Selection and cleaning: keep FQDN and URL indicators and remove duplicate values.
  2. Balancing: randomly select the same number of legitimate records as malicious records.
  3. Feature engineering: extract 31 numerical characteristics, including URL length, entropy, suspicious words, ports, subdomains, and executable extensions.
  4. Data splitting: export 80% of the records to train.csv and 20% to test.csv.

Phase 3 deliverables

The preparation script creates balanced_dataset_complete.csv, train.csv, and test.csv inside the phase3_output directory.
