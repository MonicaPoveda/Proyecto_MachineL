CRISP-DM Methodology · Phase 02 of 06

Data Understanding

Documentation of the data source, the file collected, and the initial profile of the Indicators of Compromise (IoC) dataset used to classify submitted URLs and links only.

Data collection

Data source

The data was obtained from the Colombian open data portal datos.gov.co, from the dataset “Indicadores de Compromiso – IoC” (Indicators of Compromise associated with APT actors). The dataset is published by the Ministerio de Tecnologías de la Información y las Comunicaciones (MinTIC), Bogotá D.C., through its ColCERT unit. The file downloaded and analyzed is Indicadores_de_Compromiso_-_IoC_20261106.csv.

According to the publisher, the dataset is a structured repository of IoCs identified in malicious activity attributed to Advanced Persistent Threat (APT) groups. The indicators were compiled from technical analysis, correlation of security events, and cyber threat intelligence (CTI) sources. Its stated purpose is to support early detection, prevention, and response to cybersecurity incidents by public and private entities, academia, and the technical community.

Application scope: the application analyzes submitted URLs and links only. Email addresses, email messages, and message content are not inputs or prediction targets. Of the indicator types published by the source (IP addresses, domains, URLs, file hashes, malware artifacts, behavior signatures, infrastructure patterns), only URL records and FQDN domain indicators are relevant to this project.

Data collection

Complementary source: Tranco ranking

To identify the possibility that a submitted link is legitimate, the project uses the first 20,000 rows of the Tranco domain ranking. The ranking file top-1m.csv contains 1,000,000 domains in two fields, rank and domain, and only the 20,000 best-ranked rows are kept. The domain of each submitted URL is normalized and compared with this list.

SituationResult shownMeaning
Domain is in the first 20,000 rowsPossibly legitimateThe domain is widely popular. This is an indication, not a confirmation.

Scope of this source: Tranco measures domain popularity, not safety. Appearing in the list does not guarantee that a link is safe, and popular hosting platforms can also be used to publish malicious pages.

Exploratory analysis

Patterns and initial observations

  • The file is a mixed IoC feed, not a URL-only table. URL records are the link indicators; FQDN records describe hosts; all other indicator formats are excluded from the URL-analysis workflow.
  • All 5,385 URL records have a non-empty tags value: 5,199 are tagged Comportamiento Malicioso, 77 are tagged malware, and 109 use other tag values. There are 38 distinct URL tag strings; 71 rows contain multiple pipe-separated tags.
  • The tags are the publisher's threat categories, not independently verified labels. One tag dominates and many other categories are rare.
  • No benign URL examples are present in this feed, so it cannot by itself train or evaluate a malicious-versus-legitimate detector.
  • The created_at, touched_at, and expires_at fields parsed as dates in every row, with no expiry-before-created rows detected, so they support freshness and temporal analysis.
  • tags, sources, and adversaries are metadata fields that can hold multiple values and inconsistent naming.
  • There are 37,381 distinct values across the file, so many indicators appear in more than one row.

This is a structural and quality profile, not a confirmed threat attribution or a measurement of the eventual model's predictive performance.

Conclusion

Findings from the data understanding phase

The IoC file contains only threat-related indicators. Of 5,385 URL records, 5,199 carry the tag Comportamiento Malicioso and the rest carry other threat tags; none is a benign example. The feed therefore provides malicious and threat-category URL examples, plus FQDN host indicators, but no legitimate class.
  • Source identified and documented: MinTIC / ColCERT, published on datos.gov.co, last updated October 30, 2026.
  • Usable subset: 5,385 URL records and 52,111 FQDN records out of 106,881 rows; the remaining rows are outside the application's scope.
  • Main quality issues found: 55,288 exact duplicate rows, 69,500 repeated indicator values, one record without type, and a heavily dominant tag.
  • A legitimate-URL class is not present in this source and is a requirement for malicious-versus-legitimate classification.
  • The first 20,000 rows of the Tranco ranking are used as a complementary source: a domain found there is reported as possibly legitimate, and a domain not found is reported as not detected.
  • A URL matching an indicator in this feed can be reported as a known indicator; a URL that does not match is unknown, not legitimate.
