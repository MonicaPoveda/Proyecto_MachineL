CRISP-DM Methodology · Phase 04 of 06

Modeling

Train and compare phishing classifiers using the prepared URL features. Model selection uses training data only; the held-out test set is reserved for Phase 5.

Phase objective

Select, train, tune, and compare candidate models

The input is outputs/phase3_output/train.csv, containing 33,936 training rows, 31 numeric URL features, and the target is_phishing (0 = legitimate, 1 = phishing). The separate test.csv file is not loaded during this phase.

Before fitting, the training script validates that features are numeric and have no missing or infinite values, and that both target classes are present.

1. Algorithms and parameter tuning

Three classifiers are compared

Algorithm Modeling technique Parameters searched
Logistic Regression StandardScaler followed by a class-weighted classifier. C: 0.1, 1, 10; maximum iterations: 2,000.
Random Forest Class-weighted ensemble of decision trees. 200 trees; max_depth: unrestricted or 20; min_samples_leaf: 1 or 2.
Gradient Boosting Sequentially adds trees to correct previous errors. n_estimators: 100 or 200; learning_rate: 0.05 or 0.1; max_depth: 2 or 3.

Parameter combinations are searched with GridSearchCV and stratified 3-fold cross-validation. The Random Forest search fixes the tree count at 200; it does not compare different tree counts.

2. Training and model selection

Cross-validation results

The mean F1 score is the selection metric because it balances phishing precision and recall. Accuracy, error rate, precision, recall, and ROC-AUC are recorded as complementary metrics. For each algorithm, GridSearchCV refits the best parameter combination on all training rows.

Model Mean CV F1 Mean CV accuracy Mean CV precision Mean CV recall Mean CV ROC-AUC
Random Forest — selected 95.74% 95.79% 96.92% 94.59% 98.47%
Gradient Boosting 93.91% 94.11% 97.13% 90.90% 98.02%
Logistic Regression 91.90% 92.13% 94.69% 89.26% 94.97%

The selected Random Forest uses 200 trees, unrestricted maximum depth, and a minimum of one sample per leaf. These are cross-validation selection results, not the final Phase 5 test metrics.

3. Deliverables

Trained models and reproducible results

Run the preparation and modeling scripts from the repository root:

python templates/methodology/phase3/phase3_preparation.py
python templates/methodology/phase4/phase4_modeling.py
  • outputs/phase4_output/models/: one serialized model per algorithm.
  • model_comparison.csv: cross-validation metrics and best parameters.
  • *_search_results.csv: detailed results for each searched parameter combination.
  • modeling_metadata.json: training file, feature list, and selection configuration.

Phase 4 selects Random Forest by mean cross-validation F1. Phase 5 evaluates that saved model once on the reserved test set before deciding whether it meets the project objectives.
