Project Title

Developing a Web System to Detect Phishing Risks

Problem Statement and Rationale

Why this project matters

Cybercrime has evolved into fraud ecosystems that exploit social engineering. Traditional cybersecurity solutions are often ineffective because they operate reactively and rely on a single signal, such as static blocklists that cannot keep up with new attacks. Without integrated context, these systems cannot correlate the psychological urgency of a message, structural anomalies in a link, and the sender's origin at the same time. As a result, people remain exposed to highly persuasive scams.

General Objective

Project Objective

Develop a web-based system using machine learning to detect phishing risks in links, incorporating impact analysis, security recommendations, and a preview feature.

Specific Objectives

CRISP-DM Project Phases

  • 01. Business Understanding

    Define the system's functional and non-functional requirements, risk categories, associated consequences, and success criteria (metrics and thresholds), based on a review of background information and cybersecurity reports.

  • 02. Data Understanding

    Collect, explore, and analyze the dataset of Indicators of Compromise (IoCs) from datos.gov.co, along with samples of legitimate URLs from complementary sources, to identify structural patterns that distinguish malicious links from legitimate ones and evaluate data quality and class balance.

  • 03. Data Preparation

    Clean, normalize, and transform the lexical and syntactic characteristics of URLs and IoC metadata, preparing an optimal dataset for training the machine learning model.

  • 04. Modeling

    Train, tune, and compare different machine learning classification algorithms to maximize accuracy in phishing risk detection and threat type categorization.

  • 05. Evaluation

    Evaluate the predictive model using machine learning metrics, including the confusion matrix, precision, recall, and F1-score. Validate the web interface's effectiveness in generating alerts, recommendations, and secure link previews.

  • 06. Deployment

    Implement the interactive web application by integrating the predictive model, risk analysis engine, recommendation generation, impact analysis, and external preview module for the analyzed link.

Theoretical Framework

From Reactive to Predictive Cybersecurity

This project addresses the limitations of traditional cybersecurity solutions by proposing a machine learning-based system that identifies phishing risks, explains potential consequences, and provides actionable security recommendations.

01.Transition to Predictive Approaches

Traditional security solutions often rely on static blacklists, which struggle to detect newly created domains and short-lived fraud campaigns. Machine learning offers a predictive approach by identifying patterns in URLs and adapting detection to emerging threats.

02. Technical and Methodological Foundations

Research on phishing detection has explored algorithms such as Random Forest and Support Vector Machines to analyze lexical and syntactic URL features. Other approaches examine hyperlinks without relying on page content, while CRISP-DM provides a structured process for data preparation, modeling, and evaluation.

Relevant studies: Sahingoz et al. (2019), Jain and Gupta (2020), and Silva et al. (2022).

03.Colombian Context and Open Government Data

Open government data can help adapt cybersecurity models to the local threat landscape. Indicators of Compromise (IoCs) published through datos.gov.co provide a potential source of information for identifying malicious links and studying patterns associated with cyber threats in Colombia.

04. Limitations of Current Security Solutions

Static blacklists may miss new malicious domains, while multi-engine scanners can return technical results that are difficult for non-technical users to interpret. Browser extensions may also provide limited explanations or control over how a suspicious page is inspected.

05. Our Proposed Approach

The proposed system combines three complementary features to improve phishing prevention:

Predictive Detection

Analyze URL characteristics and IoC data to estimate phishing risks.

Actionable Guidance

Explain potential consequences and provide understandable security recommendations.

Safer Link Preview

Provide an isolated preview of suspicious pages to help users recognize deceptive designs without directly visiting them.
