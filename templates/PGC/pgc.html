Project Title

Developing a Web System to Detect Phishing Risks

Problem Statement

Context and Rationale

1.1. Problem Context

Phishing is a cybersecurity threat that uses social engineering to deceive people and obtain confidential information through links that impersonate legitimate websites. Traditional solutions, which rely mainly on blacklists, have limitations when identifying new links or those that have not yet been reported.

In addition, many security tools do not clearly explain the risks associated with suspicious links or provide understandable recommendations to users. This situation highlights the need for solutions that can analyze links, identify risk patterns, and support the prevention of potential digital fraud through machine learning techniques.

1.2. Rationale

This project proposes developing a web-based machine learning system to detect potential phishing threats by analyzing URL features and Indicators of Compromise (IoC) data.

The solution aims to complement traditional mechanisms by classifying risk, presenting potential consequences, and generating security recommendations. It will also incorporate a preview through an external, controlled environment to help users understand threats.

In this way, the project seeks to contribute to phishing prevention, strengthen users' digital security, and demonstrate the usefulness of machine learning in detecting potentially malicious links.

General Objective

Project Objective

Develop a web-based system using machine learning to detect phishing risks in links, incorporating impact analysis, security recommendations, and a preview feature.

Specific Objectives

CRISP-DM Project Phases

01

Business Understanding

Define the system's functional and non-functional requirements, risk categories, associated consequences, and success criteria (metrics and thresholds), based on a review of background information and cybersecurity reports.

02

Data Understanding

Collect, explore, and analyze the dataset of Indicators of Compromise (IoCs) from datos.gov.co, along with samples of legitimate URLs from complementary sources, to identify structural patterns that distinguish malicious links from legitimate ones and evaluate data quality and class balance.

03

Data Preparation

Clean, normalize, and transform the lexical and syntactic characteristics of URLs and IoC metadata, preparing an optimal dataset for training the machine learning model.

04

Modeling

Train, tune, and compare different machine learning classification algorithms to maximize accuracy in phishing risk detection and threat type categorization.

05

Evaluation

Evaluate the predictive model using machine learning metrics, including the confusion matrix, precision, recall, and F1-score. Validate the web interface's effectiveness in generating alerts, recommendations, and secure link previews.

06

Deployment

Implement the interactive web application by integrating the predictive model, risk analysis engine, recommendation generation, impact analysis, and external preview module for the analyzed link.

Project Foundations

Theoretical Framework: From Reactive to Predictive Security

Designing a machine learning-based system to counter phishing requires moving from reactive responses toward predictive and adaptive mechanisms. Traditional blacklists rely on previously reported threats and may therefore lag behind short-lived fraud campaigns driven by social engineering.

01

Predictive Approaches

Data mining can analyze lexical and syntactic URL patterns to estimate risk without relying solely on a domain already appearing on a list of malicious sites. This approach aims to support the early identification of new or short-lived threats.

02

Technical and Methodological Foundations

Sahingoz et al. (2019) studied algorithms such as Random Forest and Support Vector Machines using lexical and syntactic URL features, reporting accuracy above 97% in their experiments, including for zero-day attacks. Jain and Gupta (2019) explored automated hyperlink feature extraction without relying on page content, avoiding the need to execute page scripts during analysis.

Silva et al. (2022) applied CRISP-DM and reported the performance of decision trees in controlled settings. These studies inform the model comparison and data workflow for this project.

03

Colombian Context and Open Data

Indicators of Compromise (IoCs) published on datos.gov.co provide an official source for studying threats associated with the Colombian landscape. Analyzing them may help contextualize the project data and identify local patterns; their availability and update frequency should be verified during dataset preparation.

04

Limitations of Current Solutions

Static blacklists may not include newly created domains. Multi-engine scanners can present technical results that are difficult to interpret, while some browser extensions provide limited explanations or control over the inspection of a suspicious link. These limitations particularly affect users without technical expertise.

05

Integrated System Proposal

The proposal combines three components to make diagnosis preventive, understandable, and user-focused:

Contextual Detection

Analyze URL features and IoC data to classify risk and help adapt the model to the local context.

Actionable Guidance

Explain the potential consequences of a link and provide clear mitigation recommendations.

Safer Link Preview

Display suspicious pages in an external, isolated environment so users can recognize deceptive tactics without opening them directly on their device.
